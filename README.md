# Python Workshop Assignments

This repository contains my Python assignments for the Git Workshop.

## Files Included:
*   `main.py`: The main script for running the program.
*   `ds.py`: Data structures exercises.
*   `class.py`: Object-oriented programming practice.
*   `assignment.py`: Course assignment code.

## How to Run:
1. Make sure you have Python installed.
2. Open your terminal in this folder.
3. Run the following command:
   python main.py
